# CRM

Manage customers, contacts, follow-ups and sales opportunities inside DooTask.
Single sign-on with your DooTask account; data is self-hosted.

## Features

- **Customers**: company/customer records with status (lead / following / signed / lost), source, tags, notes; search and status filter; a focused detail page.
- **Contacts**: multiple contacts per customer, with a primary-contact flag.
- **Follow-ups**: a timeline of every interaction, recording the follower and the next follow-up date.
- **Opportunities**: stages (initial / qualified / proposal / negotiation), owner, amount, expected close date, win/loss marking (with loss reason).
- **Owners**: every customer and opportunity has an owner, defaulting to the current user; any DooTask user can be assigned.
- **Follow-up dashboard**: "what I need to follow up" sorted by next follow-up date with overdue highlighting, plus headline stats.
- **Permissions**: configure CRM administrators at install time; admins manage all data, regular users mainly manage what they own.
- **DooTask integration**: uses the current identity; owners are DooTask users; link and open DooTask tasks.

## Installation

Install from the DooTask App Store. Pick the CRM administrators in the
"Administrator" field at install time (leave empty to treat everyone as admin).
After installation, open **CRM** from the application menu.
