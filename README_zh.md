# 客户关系管理（CRM）

在 DooTask 中管理客户、联系人、跟进记录与销售商机。复用 DooTask 账号，数据自托管。

## 功能

- **客户管理**：记录客户/公司、状态（潜在/跟进中/已成交/已流失）、来源、标签、备注；搜索与状态筛选；客户详情页集中查看。
- **联系人管理**：在客户下维护多个联系人，标记主要联系人。
- **跟进记录**：按时间线记录每次沟通，记录跟进人与下次跟进时间。
- **商机管理**：维护销售商机的阶段（初步接触/需求确认/方案报价/商务谈判）、负责人、金额、预计成交时间，标记赢单/输单（含输单原因）。
- **负责人**：客户与商机均有负责人，默认当前用户，可选择任意 DooTask 用户。
- **待跟进仪表盘**：集中展示「我需要跟进的客户/商机」，按下次跟进时间排序，过期项醒目提示；附客户数、进行中商机与金额、赢单数等概览统计。
- **权限**：安装时配置 CRM 管理员；管理员可查看与管理全部数据，普通用户主要管理自己负责的数据。
- **DooTask 集成**：使用当前登录身份；负责人基于 DooTask 用户；支持关联并打开 DooTask 任务。

## 安装

在 DooTask 应用商店中安装。安装时在「管理员」字段选择 CRM 管理员（可留空，留空时所有人按管理员处理）。安装完成后，从应用菜单打开 **客户关系管理**。
